# 🛒 텔레그램 계정 구매 가이드 (사용자용)

## 📱 구매 방법

### 1단계: 전화번호 입력
```
1. 구매할 계정 수량을 선택하세요 (1개, 2개, 또는 3개)
2. 전화번호를 입력하세요 (예: 01012345678)
3. 국가를 선택하세요 (한국, 미국, 인도 등)
```

### 2단계: 인증 코드 요청
```
1. "인증 코드 요청하기" 버튼을 클릭하세요
2. 시스템이 자동으로 인증 코드를 요청합니다
3. SMS로 인증 코드가 전송됩니다
```

### 3단계: 인증 코드 입력
```
1. SMS에서 인증 코드를 확인하세요
2. 코드 입력 창에 인증 코드를 입력하세요
3. 30분 이내에 입력해주세요
```

### 4단계: 결제
```
1. 결제 방법을 선택하세요 (TRX 또는 USDT)
2. 지정된 TRON 지갑 주소로 결제하세요
3. 결제 후 "결제 확인" 버튼을 클릭하세요
```

### 5단계: 계정 수령
```
1. 결제가 확인되면 자동으로 계정이 발송됩니다
2. 텔레그램 계정 정보 (사용자명, 비밀번호)를 받으세요
3. 바로 사용을 시작하세요!
```

## 🔧 문제 해결

### 인증 코드를 받지 못했습니다
```
1. 전화번호를 다시 확인하세요
2. SMS 수신 상태를 확인하세요
3. 5분 후 다시 요청하세요
```

### 결제가 확인되지 않습니다
```
1. 거래 해시를 확인하세요
2. TRON 스캔에서 거래 상태를 확인하세요
3. 관리자에게 문의하세요
```

### 계정을 받지 못했습니다
```
1. 결제 확인 상태를 확인하세요
2. 스팸 메시지함을 확인하세요
3. 관리자에게 문의하세요
```

## 💡 자주 묻는 질문

**Q: 계정은 어떻게 배송되나요?**
A: 결제 확인 후 자동으로 계정 정보 (사용자명, 비밀번호)가 Telegram을 통해 발송됩니다.

**Q: 환불이 가능한가요?**
A: 환불은 불가능합니다. 결제 전에 전화번호를 정확히 확인해주세요.

**Q: 어떤 결제 수단을 지원하나요?**
A: TRX (트론) 와 USDT (TRC20) 를 지원합니다.

**Q: 계정은 얼마나 오래 사용할 수 있나요?**
A: 생성일 1년 이상의 계정을 판매합니다. 장기 사용이 가능합니다.

**Q: 여러 개를 한 번에 구매할 수 있나요?**
A: 네, 1개, 2개, 3개를 선택하여 구매할 수 있습니다.
